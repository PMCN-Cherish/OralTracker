# record/ 目录索引

> 所有音频与转写文本都在这里。**新录音按"类型"放进对应子目录，文件名 `YYYYMMDD_类型.m4a`。**

| 子目录 | 放什么 | 现有内容 |
|---|---|---|
| `L0原始/` | L0 阶段三次录音 + 统一转写 | `20261018_130330.m4a`（L0-1, 94.8s）、`20261026_1621_L0-2.m4a`（L0-2, 322.8s）、`20261029_2244_L0-3.m4a`（L0-3, 89.2s）、`转写-三次同引擎对齐.txt` |
| `L1材料音频/` | TTS 生成的训练材料音频，**整周只用选定的一版** | `材料A1_标准157_Aria.mp3`（160wpm/20.3s，**本周用**）、`材料A1_进阶175_Aria.mp3`、`材料A1_英音165_Sonia.mp3` |
| `L1训练/` | 11/2 起每天的冷读、复述、测量录音 | 11/2 起：`20261102_冷读A1.m4a`、每日 `YYYYMMDD_复述A1.m4a`、11/7 的 `20261107_受控A1.m4a` 与 `20261107_自发.m4a` |

## 命名规范

```
YYYYMMDD_类型[_序号].m4a
```

| 类型 | 例子 |
|---|---|
| 冷读 | `20261102_冷读A1.m4a` |
| 复述（一天多次加 `_a`/`_b`） | `20261104_复述A1_a.m4a` |
| 受控（测量日朗读） | `20261107_受控A1.m4a` |
| 自发（测量日即兴） | `20261107_自发.m4a` |

## 周六测量日两版音频对应关系

| 文件 | 用途 | 转写要求 |
|---|---|---|
| `20261107_受控A1.m4a` | 朗读材料 A1 三句（有 54 词原文） | 算**受控 WER** |
| `20261107_自发.m4a` | 全新话题即兴 60 秒（无原文） | 算**自发分歧率** |
