## 高频卡点组对（跨录音累积，直接作 L2 教材）

| 组对 | 首次出现 | 类型 |
|---|---|---|
| `deep search` ↔ `deep research` | L0-1 | 形近/义近误取 |
| `revise` ↔ `advise` | L0-1 / L0-2 | 形近误取 |
| `technique` ↔ `technology` | L0-2 | 形近误取 |
| `kg` ↔ `km` | L0-2 | 单位/形近误取 |
| `thoughts on` ↔ `thinking of` | L0-2 | 名词化搭配 |
| **`can express` ↔ `can to express` ↔ `gonna to talk`** | L0-2 / **L0-3** | **情态/不定式家族（三次全勤之一，见下）** |
| `try to use` ↔ `try use` | L0-2 | 不定式搭配 |
| **`a advanced`**（冠词一致） | **L0-3** | 冠词 |
| **`things (that) help me`**（关系词丢失） | **L0-3** | 关系词 |

### C 家族追踪（L0 定案后新增）

| 子型 | 成员 | 出现 |
|---|---|---|
| 情态/不定式丢搭配 | can to express / try use / gonna to talk | L0-2 ×2、L0-3 ×1 |
| 缺系动词 | AI like knowledge | L0-3 |
| 冠词一致 | a advanced | L0-3 |
| 关系词丢失 | things can help me | L0-3 |
| 碎片句（无谓语/无主语） | Use my data / Improve my life / For this thing | L0-3 密集 |
