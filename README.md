## 九级阶梯（一句话版，细节在主报告）

| 级 | 靶点 | 突破条件 |
|---|---|---|
| L0 校准 | 找出卡在哪道工序 | 能说出"主卡点是 X"，且 X 在 3 次录音里重复出现 |
| L1 可懂度 | 别人听着不费劲 | **两个不同模型**转写错误率都降 ≥50% |
| L2 提取速度 | 把已知的词变快 | 同题第二说，**>2 秒静默停顿**降 ≥30% |
| L3 句型骨架 | 有话能立刻组句 | 5 秒内为同一意思说出三种句式 |
| L4 流利度 | 停顿少、修复快 | 3 分钟独白 >2 秒停顿 ≤3 次，且 **CV 下降** |
| L5 协商互动 | 能对话而非独白 | 主动追问 ≥3 次 / 被打断 5 秒接回 |
| L6 真实迁移 | 对真人也不崩 | 真人 10 分钟不中断 |
| L7 稳定维持 | 不掉 | 停 2 周回到基线 80% |
| L8 精修 | 说得准说得体 | 一意三版（简单/详细/正式） |

**这是依赖顺序，不是难度顺序。L1 不过，L2 的测量全是噪声。**

## 三句话（全篇最省事的版本）

1. **你不是词不够，是词调不出来** → 练"同题重复 + 同义替换"，不练"背新词"。
2. **AI 只在一个位置不可替代：给你无限次低压力的提取练习。** 它的追问、压力、"听不懂怎么办"都得你自己设规矩或找真人补。
3. **每级只认一个数，数不动就不进下一级。**

一条剂量硬结论：**同题重复 3–5 遍**（Lambert 2016）。每天换新题 = 永远停在第 1 遍。
