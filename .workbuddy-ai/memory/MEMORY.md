## 方法论要点（用户日常照此执行）
- 九级阶梯是依赖顺序不是难度顺序，每级只认一个可测数，不过不进下一级
- L0 = 1 个话题 × 3 次 90 秒录音 + AI 四分类找主卡点（第 1/3 次都出现的才是能力问题）。**已执行完毕（10/30 结案）：主卡点 B+C 并行，C 上游**
- L1 = 一周一段 ≤30 秒材料（自写、内嵌自己的错误模式），任务换层（盲听→跟读→脱稿复述→改音重录），3–5 遍同一 15 分钟连做；判据 = 受控 WER 降 ≥50% + **换新话题**自发分歧率降 ≥25%（防同题污染；自发口径无原文，用两模型转写分歧率）
- 剂量硬结论：同题重复 3–5 遍买的是"说得对/复杂"，不是"说得快"；提速度靠同义替换和句块化（Abdi Tabari 2025）
- 工具花钱口径：唯一值得付费的是 L1 的 ELSA，且只开 1 个月，当音段诊断仪用
